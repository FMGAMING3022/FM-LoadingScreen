# FM Script — FiveM Loading Screen

A modern loading screen resource for FiveM, designed to give your server a clean and professional first impression.

## ✨ Overview

**FM Script Loading Screen** brings a polished visual experience to your FiveM server while players connect. Customize it to match your server's identity and create a consistent experience for your community.

## 🚀 Features

- Modern and clean UI design
- Customizable server branding
- Immersive loading experience
- Designed for FiveM servers
- Easy resource installation
- Customization options based on the included files

## 📦 Installation

1. Download or clone this repository.
2. Place the resource folder inside your server's `resources` directory.
3. Open your `server.cfg`.
4. Add the following line:

```cfg
ensure FM-LoadingScreen
```

5. Restart your server or start the resource.
6. Connect to your server and check the loading screen.

> **Note:** If the resource folder has a different name, replace `FM-LoadingScreen` with the actual folder name.

## ⚙️ Configuration

Before making changes, review the resource files for available configuration options.

Depending on the included files, you may be able to customize:

- Server name and branding
- Logo and background assets
- Colors and visual styling
- Text and other displayed content

Always keep a backup before editing the original files.


## 🛠️ Troubleshooting

**Loading screen does not appear**
- Confirm the resource is inside your server's `resources` directory.
- Check that the resource name in `server.cfg` is correct.
- Check the server console and client F8 console for errors.

**UI or assets are missing**
- Verify that all required files are included.
- Check file paths and the resource manifest.
